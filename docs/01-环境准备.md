# 环境准备（Windows）

目标：把本机从「只有 JDK 8 + MySQL 客户端」调整到能跑 Spring Boot 3.5 + Vue 3 的状态。
以下命令在 **PowerShell** 中执行，涉及安装/服务的需要**管理员**权限。

---

## 1. 安装 JDK 21

当前 `java -version` 为 1.8.0_261，`JAVA_HOME=D:\JDK1.8`，**无法启动 Spring Boot 3.x**。

1. 下载 Temurin 21（MSI）：
   https://adoptium.net/temurin/releases/?version=21
2. 安装时勾选 “Set JAVA_HOME variable”。
3. 验证：

```powershell
java -version          # 期望 21.x
echo $env:JAVA_HOME    # 期望指向 JDK 21
mvn -v                 # 期望 Java version: 21
```

4. 如果 `JAVA_HOME` 仍指向 1.8：

```powershell
[Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Program Files\Eclipse Adoptium\jdk-21...", "Machine")
```

5. IDEA：`File → Project Structure → SDK` 选 21；`Settings → Build Tools → Maven → Runner → JRE` 选 21。
   VSCode：安装 “Extension Pack for Java”，`java.configuration.runtimes` 指向 21。

> 不要卸载 JDK 8，老项目可能还要用；靠 `JAVA_HOME` 和 IDE SDK 切换即可。

## 2. 升级 Git 并打通 GitHub

当前 Git 2.20.1，且访问 GitHub 报 `SSL_ERROR_SYSCALL 10054`。

1. 安装最新 Git for Windows：https://git-scm.com/download/win
2. 如果公司网络需要代理：

```powershell
git config --global http.proxy  http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890
```

3. 测试：

```powershell
git ls-remote https://github.com/tutuchacha/AI_app.git
```

4. 若 HTTPS 始终不通，改用 SSH：

```powershell
ssh-keygen -t ed25519 -C "your@email.com"
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub   # 加到 GitHub → Settings → SSH keys
ssh -T git@github.com
git remote set-url origin git@github.com:tutuchacha/AI_app.git
```

## 3. 启动 MySQL 并建库

已确认：MySQL 8.0.29 已安装，服务名 `mysql`，当前 **Stopped**。

```powershell
# 管理员 PowerShell
net start mysql

# 验证端口
Get-NetTCPConnection -LocalPort 3306 -State Listen
```

登录并建库（把密码换成你的 root 密码）：

```powershell
mysql -u root -p
```

```sql
CREATE DATABASE ai_app
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;

CREATE USER 'ai_app'@'localhost' IDENTIFIED BY 'change_me';
GRANT ALL PRIVILEGES ON ai_app.* TO 'ai_app'@'localhost';
FLUSH PRIVILEGES;
```

验证：

```powershell
mysql -u ai_app -p -e "SHOW DATABASES LIKE 'ai_app';"
```

> 应用不要用 root；密码写进 `application-local.yml` 或环境变量，仓库里只留 `.env.example`。

## 4. 选择模型服务

### 方案 A：本地 Ollama（推荐先跑通，免费）

1. 安装：https://ollama.com/download/windows
2. 拉模型（按显存选择，7B 量化约需 6–8GB）：

```powershell
ollama pull qwen2.5:7b
ollama pull bge-m3          # 中文 Embedding
ollama list
```

3. 验证 OpenAI 兼容接口：

```powershell
curl http://127.0.0.1:11434/v1/chat/completions `
  -H "Content-Type: application/json" `
  -d '{\"model\":\"qwen2.5:7b\",\"messages\":[{\"role\":\"user\",\"content\":\"你好\"}]}'
```

### 方案 B：云端 OpenAI 兼容 API

任选其一，先充值少量额度：

| 服务 | base-url | 常用模型 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode` | `qwen-plus` / `text-embedding-v3` |
| 月之暗面 | `https://api.moonshot.cn` | `moonshot-v1-8k` |
| OpenAI | `https://api.openai.com` | `gpt-4o-mini` / `text-embedding-3-small` |

> 一套 OpenAI 协议适配所有服务，靠 `ai_model` 表切换，不要把模型名写死在代码里。

## 5. Nginx / Prometheus / Grafana（无 Docker）

统一解压到 `D:\tools\`（不要放在仓库内，避免提交二进制）：

| 工具 | 下载 | 默认端口 |
| --- | --- | --- |
| Nginx | https://nginx.org/en/download.html | 80 |
| Prometheus | https://prometheus.io/download/ | 9090 |
| Grafana | https://grafana.com/grafana/download?platform=windows | 3000 |

启动示例：

```powershell
# Nginx（配置使用仓库内 infra/nginx/nginx.conf）
D:\tools\nginx\nginx.exe -c D:\AI_learn\infra\nginx\nginx.conf

# Prometheus
D:\tools\prometheus\prometheus.exe `
  --config.file=D:\AI_learn\infra\prometheus\prometheus.yml `
  --storage.tsdb.path=D:\tools\prometheus\data

# Grafana
D:\tools\grafana\bin\grafana-server.exe --homepath D:\tools\grafana
```

Grafana 首次登录 `admin/admin`，添加 Prometheus 数据源 `http://127.0.0.1:9090`，
再导入 `infra/grafana/dashboards/` 下的 JSON。
