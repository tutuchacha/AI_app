# 接口约定（M0 起）

> 前后端唯一契约；改契约同步本文件、`backend.md`、`ARCHITECTURE.md` 与前端封装。

## 1. 基础约定

- 前缀：业务接口以 `/api` 开头（Vite 代理 8080）
- 编码：`application/json;charset=UTF-8`；字段 `camelCase`
- 鉴权：`Authorization: Bearer <token>`（`/api/auth/**` 除外）
- TraceId：可带，不传则生成 16 位并回显响应头
- 成功码固定为 `0`；失败码与 HTTP 状态码一致
- 在线文档：`127.0.0.1:8080/swagger-ui.html`（Authorize 填 token）

## 2. 统一响应体

```json
// 成功
{ "code": 0, "message": "成功", "data": { "username": "demo" }, "traceId": "18a1eda07c2c4269" }

// 失败（data 恒为 null）
{ "code": 400, "message": "username: 不能为空", "data": null, "traceId": "18a1eda07c2c4269" }
```

| code | HTTP | 含义 | 前端动作 |
| --- | --- | --- | --- |
| 0 | 200 | 成功 | 取 `data` |
| 400 | 400 | 参数错误 | 直接提示 `message` |
| 401 | 401 | 未登录 / token 过期 | 清 token，跳 `/login` |
| 403 | 403 | 无权限 | 提示无权限 |
| 404 | 404 | 接口或资源不存在 | 提示 + 上报 traceId |
| 409 | 409 | 数据冲突（如用户名已存在） | 提示换一个 |
| 429 | 429 | 触发限流（轮数超限） | 提示稍后重试，可禁用输入 |
| 500 | 500 | 服务端异常 | 提示稍后重试，附 traceId |
| 502 | 502 | 上游模型调用失败 | 提示可重试 |
| 503 | 503 | 未配置模型密钥 | 提示配置 `DASHSCOPE_API_KEY` |
| 504 | 504 | 模型响应超时 | 提示可重试 |

## 4. 鉴权接口（M0-B04）

| 方法 | 路径 | 请求体 | 响应 `data` |
| --- | --- | --- | --- |
| POST | `/api/auth/register` | `{ username, password, nickname? }` | `{ id, username, nickname }` |
| POST | `/api/auth/login` | `{ username, password }` | `{ token, username, nickname }` |
| GET | `/api/auth/me` | 头带 Bearer token | `{ id, username, nickname, role }` |

密码 8–32 位含字母数字；用户名 3–32 位；JWT 2h。

## 5. 聊天接口（M1）

| 方法 | 路径 | 请求体 | 响应 `data` |
| --- | --- | --- | --- |
| POST | `/api/chat` | `{ content, conversationId?, module?, model?, retry?, kbId? }` | `{ conversationId, content, model, promptTokens, completionTokens, latencyMs, citations }` |

- `content` 1–4000；`conversationId` 留空由后端生成（`c_`）；`model` 留空用 `qwen-plus`
- 带 `conversationId` 取最近 20 条上下文；`retry: true` 不新增提问，旧半截回答标 `FAILED`
- `kbId` 可选：检索片段注入并回落 `citations[{id,title,snippet,score}]`；绑定会话，可不传
- 归属落库前校验：403/404；检索失败降级为无引用回答
- 错误：401 / 403 / 502 / 503 未配密钥 / 429（20 轮/分）/ 504（60s）

### SSE `/api/chat/stream`（M1-03）

- 响应 `text/event-stream` + `no-cache`；`data: {"type":"delta","content":"你"}`
- 顺序 `meta → citation* → delta* → usage → done`，出错 `meta → error`；断连即取消上游
- `citation` 帧：`{"type":"citation","citation":{id,title,snippet,score}}`
- 错误 `code`：`RATE_LIMITED` / `LLM_TIMEOUT` / `MODEL_ERROR` / `MODEL_NOT_CONFIGURED` / `KB_NOT_FOUND` / `FORBIDDEN` / `INTERNAL_ERROR`
- `done.finishReason`：`stop` / `length` / `stopped`；字段见 `modules/chat.md` §4

### WS `/ws/chat`（M1-09 持久连接）

- 握手 `?token=<JWT>`，一次多轮；帧 `{"type":"chat|stop|ping"}`，`stop` 只取消当前轮，20s 心跳 + 重连

### 会话 `/api/conversations`（M1-05）

| 方法 | 路径 | 参数 | 响应 `data` |
| --- | --- | --- | --- |
| GET | `/api/conversations` | `module?`（默认不筛） | `[{ uid, title, module, lastMessageAt }]`，时间倒序 ≤50 |
| GET | `/api/conversations/{uid}` | 路径参数 | `{ uid, title, module, kbId, messages[] }`（消息字段见 `modules/chat.md` §4） |

- 仅自己的会话（403/404）；详情只含 `DONE/STOPPED` 非空消息，id 正序 ≤200
- 时间本地 ISO-8601，前端自格式化

## 6. 知识库接口（M2）

- 字段/状态机/校验见 `modules/rag.md` §1~§3；响应体遵循 §2
- 上传：`POST /api/knowledge-bases/{id}/documents`，multipart `file` ≤20MB，返回 `PENDING`
- 归属 403/404；解析失败 `status=FAILED` + `errorMsg`；`READY` = 已切 + 已向量化
- 检索：`POST /api/knowledge-bases/{id}/search`，body `{query, topK?, minScore?}`，score 倒序，默认 6 片 / 0.2

## 7. 文档分析接口（M3）

- `POST /api/documents/{documentId}/analysis`，body `{type}`；须 `READY`，默认立即返回 `PENDING`
- `GET /api/documents/{documentId}/analysis`（id 倒序 ≤20）；`GET/DELETE /api/analysis/{id}`
- `type` = `SUMMARY / OUTLINE / QUESTIONS`；`content` 为 Markdown；`status` = `PENDING/RUNNING/READY/FAILED`
- 同文档同类型已有 `PENDING/RUNNING` 复用；归属同文档（403 / 404）

## 8. 前端使用建议

```ts
const body = await res.json()
if (body.code !== 0) { if (body.code === 401) auth.logout(); throw new Error(`${body.message}（${body.traceId}）`) }
return body.data
```

- 不要依赖 HTTP 200，只看 `code === 0`
- 报错带 `traceId`；前端封装见 `src/api/http.ts`（token、解包、401 清理）
