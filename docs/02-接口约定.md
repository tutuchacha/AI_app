# 接口约定（M0 起）

> 前后端唯一契约；改契约同步本文件、`backend.md`、`ARCHITECTURE.md` 与前端封装。

## 1. 基础约定

- 前缀：所有业务接口以 `/api` 开头（Vite 代理到 8080）
- 编码：`application/json;charset=UTF-8`；字段 `camelCase`
- 鉴权：`Authorization: Bearer <token>`（M0-B04 起，`/api/auth/**` 除外）
- TraceId：请求可带，不传则服务端生成 16 位并回显响应头
- 成功码固定为 `0`；失败码与 HTTP 状态码一致
- 在线文档：`http://127.0.0.1:8080/swagger-ui.html`（Authorize 填 token）

## 2. 统一响应体

```json
// 成功
{ "code": 0, "message": "成功", "data": { "username": "demo" }, "traceId": "18a1eda07c2c4269" }

// 失败（data 恒为 null）
{ "code": 400, "message": "username: 不能为空", "data": null, "traceId": "18a1eda07c2c4269" }
```

| code | HTTP | 含义 | 前端动作 |
| --- | --- | --- | --- |
| 0 | 200 | 成功 | 取 `data` |
| 400 | 400 | 参数错误 | 直接提示 `message` |
| 401 | 401 | 未登录 / token 过期 | 清 token，跳 `/login` |
| 403 | 403 | 无权限 | 提示无权限 |
| 404 | 404 | 接口或资源不存在 | 提示 + 上报 traceId |
| 409 | 409 | 数据冲突（如用户名已存在） | 提示换一个 |
| 429 | 429 | 触发限流（轮数超限） | 提示稍后重试，可禁用输入 |
| 500 | 500 | 服务端异常 | 提示稍后重试，附 traceId |
| 502 | 502 | 上游模型调用失败 | 提示可重试 |
| 503 | 503 | 未配置模型密钥 | 提示配置 `DASHSCOPE_API_KEY` |
| 504 | 504 | 模型响应超时 | 提示可重试 |

## 4. 鉴权接口（M0-B04）

| 方法 | 路径 | 请求体 | 响应 `data` |
| --- | --- | --- | --- |
| POST | `/api/auth/register` | `{ username, password, nickname? }` | `{ id, username, nickname }` |
| POST | `/api/auth/login` | `{ username, password }` | `{ token, username, nickname }` |
| GET | `/api/auth/me` | 头带 Bearer token | `{ id, username, nickname, role }` |

密码规则：8–32 位，至少含字母和数字；用户名 3–32 位。JWT 有效期 2h。

## 5. 聊天接口（M1）

| 方法 | 路径 | 请求体 | 响应 `data` |
| --- | --- | --- | --- |
| POST | `/api/chat` | `{ content, conversationId?, module?, model?, retry?, kbId? }` | `{ conversationId, content, model, promptTokens, completionTokens, latencyMs, citations }` |

- `content` 1–4000 字；`conversationId` 留空由后端生成（`c_` 前缀）；`model` 留空用 `qwen-plus`
- 带 `conversationId` 时取该会话最近 20 条做上下文；`retry: true` 重试上一轮：不新增提问，旧半截回答标 `FAILED`
- `kbId` 可选：检索该库片段注入提示词并回落 `citations[{id,title,snippet,score}]`；库绑定到会话，后续轮次可不再传
- 库归属在落库前校验：别人的 403、不存在 404；检索失败降级为普通回答（无引用），不中断聊天
- 错误：401 / 403 非本人会话或库 / 502 / 503 未配密钥 / 429（20 轮/分）/ 504（60s）

### SSE `/api/chat/stream`（M1-03）

- 响应 `text/event-stream` + `no-cache`；每帧 `data: {"type":"delta","content":"你"}`
- 顺序 `meta → citation* → delta* → usage → done`（有引用时 citation 在 delta 前），出错为 `meta → error`；断连即取消上游
- `citation` 帧：`{"type":"citation","citation":{"id":"12","title":"手册.pdf","snippet":"...","score":0.83}}`
- 错误 `code`：`RATE_LIMITED` / `LLM_TIMEOUT` / `MODEL_ERROR` / `MODEL_NOT_CONFIGURED` / `KB_NOT_FOUND` / `FORBIDDEN` / `INTERNAL_ERROR`
- `done.finishReason`：`stop` / `length`（达 `max-tokens`）/ `stopped`；字段见 `modules/chat.md` §4

### WS `/ws/chat`（M1-09 持久连接）

- 握手 `?token=<JWT>`，一次握手多轮；帧 `{"type":"chat|stop|ping"}`，`stop` 只取消当前轮，20s 心跳 + 断线重连

### 会话 `/api/conversations`（M1-05）

| 方法 | 路径 | 参数 | 响应 `data` |
| --- | --- | --- | --- |
| GET | `/api/conversations` | `module?`（默认不筛） | `[{ uid, title, module, lastMessageAt }]`，按最后消息时间倒序，最多 50 条 |
| GET | `/api/conversations/{uid}` | 路径参数 | `{ uid, title, module, messages: [{ id, role, content, status, tokensIn, tokensOut, latencyMs, model, citations, createdAt }] }` |

- 只返回自己的会话：别人的 403、不存在 404；详情只含 `DONE/STOPPED` 非空消息，id 正序，≤200 条
- 时间为本地 ISO-8601，前端自行格式化

## 6. 知识库接口（M2）

- 端点、字段、状态机与校验规则统一见 `modules/rag.md` §1~§3；响应体遵循本文件 §2
- 上传：`POST /api/knowledge-bases/{id}/documents`，multipart `file`，≤20MB，返回 `PENDING`
- 归属：别人的 403、不存在 404；解析失败为 `status=FAILED` + `errorMsg`
- `READY` = 文本已切 + 向量已写；`embedding` 存 JSON 数组
- 检索：`POST /api/knowledge-bases/{id}/search`，body `{query, topK?, minScore?}`，按 score 倒序；默认 6 片 / 阈值 0.2

## 7. 前端使用建议

```ts
const body = await res.json()
if (body.code !== 0) { if (body.code === 401) auth.logout(); throw new Error(`${body.message}（${body.traceId}）`) }
return body.data
```

- 不要依赖 HTTP 200 判断业务成功，只看 `code === 0`
- 报错提示带 `traceId`；前端已封装 `src/api/http.ts`（注入 token、解包、401 清理）；`VITE_USE_MOCK=true` 离线
